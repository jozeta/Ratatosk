Access & Authentication

Anonymous uploadingiLets visitors encrypt and upload a file without creating an account. Turn off to require login before anyone can upload.
Allow drop-and-go uploads without an account
Anonymous downloadingiLets anyone with a share link decrypt and download the file without logging in. Turn off to force login before any download - useful if you want every download traceable to an account.
Allow public link access without login (off = force login before download)
User registrationiControls whether the public /register page accepts new sign-ups. Turn off for invite-only - an admin can still create accounts from User Management.
Public sign-ups vs. invite-only
User loginiControls whether non-admin accounts can log in. Admins can always sign in, even when this is off - the /login page itself stays reachable, it's just removed from the navigation.
Off = only admins can log in (still reachable at /login directly)
Allow secondary passphraseiLets uploaders set a passphrase at all. Turning this off removes the option entirely from the upload form and also turns off "Enforce" below, since there'd be nothing to enforce.
Show the passphrase option on the upload form
Enforce secondary passwordiRequires every uploader to set a passphrase. In this mode the encryption key is derived from the passphrase (PBKDF2) instead of a random key in the link, and the server rate-limits guesses against it.
Force uploaders to set a passphrase
User-to-user sharingiLets a logged-in uploader pick specific registered users to share a file with. Those users see it under "Shared With Me" and can decrypt it just by being logged in - no link or passphrase needed. Only available for files uploaded without a secondary passphrase, since the server never has that key. Recipients see who else the file was shared with and who shared it.
Allow sharing files directly with other accounts

Multi-Factor Authentication

Enable MFAiTurns the two-factor authentication feature on or off site-wide. Off hides it everywhere (including the Profile page) and existing setups stop being prompted at login - they aren't deleted, just dormant.
Let users set up and use an authenticator app
Require for regular usersiNon-admin accounts without MFA set up will be walked through setup immediately after their next successful password login, before they can do anything else.
Force MFA setup at next login
Require for adminsiSame as above, for admin accounts. Worth turning on independently of regular users, since admin accounts are the highest-value target.
Force MFA setup at next login

Login Security

Account login rate limitingiLocks an account out for a while after too many wrong passwords in a row, to block brute-force guessing. Applies to every account, including admins. Uses the "Max login/password attempts" value from Privacy & Audit.
Lock accounts out after repeated failed logins

Password Policy

Applied to registration, admin-created accounts, password resets, and self-service password changes.

Require uppercase letteriPasswords must contain at least one A-Z character.
Require lowercase letteriPasswords must contain at least one a-z character.
Require numberiPasswords must contain at least one digit (0-9).
Require special characteriPasswords must contain at least one non-alphanumeric character, e.g. ! @ # $ %.

Admin Feature Views

User managementiShows or hides the entire /admin/users page and its API. Turning it off blocks user CRUD even for admins who navigate there directly - a way to reduce attack surface when you don't need it.
Show/hide the User Management page entirely
File managementiShows or hides the entire /admin/files page and its API (viewing/deleting any file platform-wide). Turning it off blocks it even for admins who navigate there directly.
Show/hide the File Management page entirely
API keysiLets logged-in users create API keys for scripted/CLI uploads (see /account and the cli/ folder). Turning this off immediately stops all existing keys from working too.
Allow API keys for CLI/scripted uploads

Extreme Anonymity Engine

Zero-log mode (uploads)iWhen on, upload events are recorded only as an anonymous ANON_UPLOAD entry with no IP, user agent, or account link at all - overrides the IP obfuscation level below for uploads specifically.
Disable IP/UA/precise-timestamp logging for uploads

Audit & Security

Disable audit loggingiStops all new events from being written to the audit log - uploads, downloads, logins, admin actions, everything. Existing entries are kept until pruned. Turning this on cannot itself be logged, since logging is off by the time the change takes effect.
Stop recording new audit log entries entirely
Rate-limit abuse-prone requestsiLimits logins, registrations, password resets, anonymous upload starts and passphrase checks per client network. Counted in memory only - never written to disk.
Slow down guessing and flooding from any one network
