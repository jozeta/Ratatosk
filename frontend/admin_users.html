i The CSV needs a header row with username and password columns, plus optional email and is_admin columns (is_admin: true/false, defaults to false). One user per row after that. Example:
username,password,is_admin alice,Str0ngPass!23,false bob,Str0ngPass!45,true Max 1000 rows, 1MB file, UTF-8 encoded. Rows that fail (duplicate username, weak password, etc.) are skipped and reported - everything else still imports. Use "Download template" for a ready-made starting file.
